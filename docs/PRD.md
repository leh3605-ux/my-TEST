# 사이트 설계도(PRD) — 바이블가이드

작성일: 2026-11-15 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
성경을 처음 읽는 사람이 함께 배우는 온라인(줌) 성경 공부 모임·강의.

## 2. 손님
- 누가: 성경을 처음 읽는 사람
- 어디서 알고 오나: 지인·교회 소개 (받은 링크를 눌러서 들어온다)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 초보도 괜찮나요?
2. 언제·어디서 하나요?
3. 무엇을 배우나요?

## 4. 믿게 할 증거 (실제로 있는 것만)
- 아직 없음 (모임 사진·인도자 소개는 준비되면 넣는다)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 첫 모임 체험하기
- 누르면: 문의 폼 (체험 신청)

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + [첫 모임 체험하기] 버튼
2. 처음이어도 괜찮아요 — 초보를 위한 모임이라는 설명
3. 이렇게 진행해요 — 온라인(줌) · 비용 없음 · 원하는 요일·시간에 맞춤
4. 무엇을 배우나요 — 배우는 내용 (미정: 사용자가 채운다)
5. 후기 자리 (비워 둠)
6. 문의 폼 — 첫 모임 체험 신청

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 원하는 요일·시간
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 없음
- 시간: 원하는 요일·시간을 적어 주면 맞춘다
- 위치: 온라인 (줌)
- 연락 방법: 사이트에 메모 남기기 (문의 폼)

## 9. 이번에 넣지 않을 것
- 결제 (비용이 없음)
- 회원가입·로그인
- 블로그·자료실
- 알림 메일

## 10. 첫 화면 한 문장 후보
1. 성경, 처음이어도 괜찮아요. 함께 천천히 읽어요.
2. 혼자 읽기 어려웠던 성경, 줌으로 편하게 같이 배워요.
3. 원하는 시간에, 집에서, 비용 없이 시작하는 성경 공부.

## 11. 다음에 할 것
- "무엇을 배우나요" 내용 채우기 (어떤 책을, 어떤 순서로, 몇 주 동안)
- 인도자 소개와 모임 사진 넣기
- 실제 참여자 후기가 생기면 후기 자리에 넣기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. (9번이 '예'일 때) 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
